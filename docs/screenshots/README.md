# Capturas de tela do Ateliê de Dados

Esta pasta recebe as capturas reais da aplicação para a galeria visual do README principal.

## Como enviar

- Envie as capturas originais em PNG ou JPEG.
- Prefira nomes descritivos, por exemplo: `01-apresentacao.png`, `02-bancada-completa.png`, `03-guia-etapa-01.png`.
- Não é necessário editar, recortar ou compactar as imagens antes do envio.
- As imagens desta pasta serão avaliadas para selecionar uma galeria concisa, representativa e sem duplicidade.

A galeria será organizada por experiência: apresentação, bancada 3D, etapas do pipeline, análise/relatório, desafios, glossário e cenários.
