# Security Policy

## Reporting a vulnerability

Please do not report security vulnerabilities through public issues. Contact the repository owner privately through the contact options on the GitHub profile:

https://github.com/enps2015

## Scope

The Ateliê de Dados is a static, browser-side educational application. Do not submit API keys, passwords, personal data, or private credentials in issues or pull requests.

The project does not require a Gemini API key or server-side environment variables to run as a GitHub Pages site.
